# Surface Brief: Kestrel New Tab

- **Target:** `ui/newtab/newtab.html`
- **Visitor mode:** Operate
- **Audience & Job:** Daily Linux desktop user opening a new tab (`Ctrl+T`) to immediately search, navigate to a URL, or jump to a pinned site without visual clutter or RAM overhead.

## Direction contract

THESIS: A quiet, keyboard-first dark-room browser launchpad — pure matte graphite with 1px hairline rules and zero glowing pills, gradients, or card-grid bloat.

OWN-WORLD: Restrained Swiss/Braun utilitarian instrument — `#111317` matte ground, `#181b21` recessed input, `#232730` 1px hairline rules, `#e6e9ef` primary ink, `#8b93a1` muted ink, `#e09f3e` kestrel-amber focus rule.

STORY: The user opens a tab, sees a calm, instant-focus command bar and compact pinned links with a single quiet protection line, types or clicks, and is gone in under two seconds.

FIRST VIEWPORT: Single centered column (`max-width: 620px`) with a 1-line header (`Kestrel` + custom emblem left, quiet tabular protection summary right), a crisp 1px-bordered search/URL bar with inline engine tabs, and a compact 4-column hairline-ruled shortcut list below.
